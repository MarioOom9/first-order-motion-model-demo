# First Order Motion Model Demo for Image Animation

This repository contains an academic computer vision experiment using the First Order Motion Model for Image Animation.

## Project Overview

The project explores how deep learning can be used to animate a source image based on motion extracted from a driving video. It was part of my AI-Pro diploma graduation work and focuses on experimentation, output generation, and similarity-based evaluation.

## Topics Covered

- Computer Vision
- Deep Learning
- Image Animation
- Generative AI Concepts
- Video Processing
- Frame-Level Similarity Evaluation
- Python Implementation

## Main Workflow

1. Set up the First Order Motion Model environment.
2. Load source images and driving videos.
3. Generate animated video outputs.
4. Extract frames from original and generated videos.
5. Compare generated outputs using cosine similarity.
